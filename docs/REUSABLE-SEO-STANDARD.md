# Korea reusable SEO standard — nine-module starter

This is a requirement template for future GitHub repositories, **not a universal script that can be copied without configuration**. Recheck language, build stack, domain and content source.

1. Technical indexability (HTTPS, robots, sitemap, canonical, 200/301/404).
2. Site architecture (silo, hub, breadcrumb and internal links).
3. On-page SEO (title, meta description, single H1, OG, language).
4. Content quality (original search intent, citations, legal/safety claims, readable local language).
5. Mobile and accessibility (viewport, navigation, LCP/CLS/INP lab vs real-user data).
6. Analytics (GSC and Bing account properties; actual indexed/excluded metrics).
7. AEO/GEO and structured data (visible FAQ, Article, entity identity, citation-worthy primary facts).
8. QA automation (read-only monitor independent of the writer/publisher; reports and alert on regressions).
9. Authority and distribution (verified business identity, earned editorial references, country-specific crawler access where relevant).

These are operational workstreams, not nine independent Google ranking factors.

To reuse, change site.domain, post manifest paths, language, article minimum, taxonomy and render mechanism. Never copy Korean content, NAP, writer state or sitemap into a new brand's repo. Index counts cannot be derived from HTML; real mobile CWV cannot be inferred from generated site files.
